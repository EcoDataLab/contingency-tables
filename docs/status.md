# Research status

Updated October 8, 2026.

This repository is being established from the preserved [initial review](../115/115-contingency-tables-review.md). Its proposed inverse-gap exponents of 85 and 33 are candidates. Finite checks are not a general proof, and an inverse-gap exponent is not the complete sampler's bit-complexity exponent.

Work in progress:

1. Audit localized leaf energy, global edge ownership, and sharper log-concave path constants.
2. Check generic padding/bin/threshold scales against every dependent source lemma.
3. Derive smaller certified error schedules and exact-correction precision.
4. Build exact bounded-table and weighted reference samplers with explicit resource limits.
5. Verify pinned Lean modules and record the limits of the verification environment.
6. Specify public, synthetic CBEI/LEHD examples and compare target distributions.

The original manuscripts and dependencies are pinned. No full upstream Comparator success or general practical runtime improvement is claimed at this checkpoint.
