## Semantic checks

**Raw completion and labels.** The completion wrapper computes coarse margins in the existing large-line order. It converts the stored second profile list through its capacity complement before constructing column margins. Its exact source-dependent bit count and prefix identify the unchanged frozen completion draw; a sufficiently long reservation is explicit in the correspondence theorem. Ordered label extraction uses both profile views and the established `repairLabelTest` equivalence with actual capacity bounds. Uniqueness identifies the exact ordered s/t pair, including shared-row or shared-column labels. Automatic correction therefore needs neither a supplied full source matrix nor semantic defect labels: it reconstructs the retained source, finds the labels and preserves padding/coin failures exactly. These equations are on valid actual encoded states and residuals; they do not validate arbitrary malformed raw codes.

**Incoming acceptance, exits and the joined walk.** Incoming completion is drawn at the current source, not the proposed target. Exhaustion, unused proposal slots and rejected translation retain the source. The no-proposal branch avoids its completion draw. Balanced-star trials also use their fixed balanced source, project balanced/held-balanced output to failure, and accept every defective output including one equal to the entering fallback. Each retry uses that same balanced source and the original entering defect on total failure.

The joined wrapper preserves a subtle pointwise requirement: the exit starts immediately after the *actual* incoming completion block. Unused uniform-completion slack is a final suffix after the common exit bank. Putting that slack before the exit could preserve an independence law while changing outputs on the same word; the inspected code avoids that mistake. Each reached defect receives a fresh fixed-width block. The concrete step equation discharges the generic iteration premise, so the final walk theorem identifies the actual stronger joined trace, rather than merely supplying a conditional fold helper. Zero attempts and zero walk length retain the intended fallback/start.

**Schedules and other branches.** Raw list arithmetic matches the existing dimension, catalog counts, residual mass bound, clock denominator, gap/base counts, local exit settings, uniform step bank, terminal suffix and min-linear outer settings. It introduces no replacement accuracy premise. The fallback code calls the existing legacy draw with its own computed scales and reservation; its exact statement covers every natural precision, including zero. Literal zero restoration preserves original positions. The deterministic raw output is a constant restored greedy table; its code equality needs equal totals, while uniformity still belongs to the guarded deterministic branch theorem.

**Complete corrected trial.** The ordinary trial computes its inner schedule, splits off the independent correction suffix, then splits the remaining bank into the concrete joined walk and fresh terminal completion. The terminal draw is retained during source reconstruction, automatic label extraction, repair, padding test and bounded coin. The final same-word equation identifies the whole `terminalCorrectedWord`, including exact `none` paths. It introduces no supplied per-step commuting contract, desired law or completion-accuracy assumption. A valid actual encoded start remains its input; outer composition must supply initialization and retries.

**Whole ordinary program.** The top-level function takes only original margin lists, t and a bit list. It checks equal totals internally; unequal totals return the empty code. On equal totals, it computes the branch, searched initialization, fixed-start trial retries, greedy fallback and ordered zero restoration. Input is capped at R complete q-bit trial blocks; positivity of q is explicitly proved for the reference call. Extra bits cannot add attempts. Sigma transport keeps the chosen width and typed map coherent. The final exact statement covers every reserved word on every equal-total input, including empty lists and t=0, with no semantic table, start, residual, labels, step contract or desired-law input.

**Standalone ordinary-program contract.** The checked `executableSampler_contract` takes only the original natural margin lists, their ordinary sum equality and natural t. It binds the reserved q exactly to `rawHybridWordWidth`, identifies the actual raw output with a feasible Table-valued interpretation on every word, and proves uniform-word total variation at most `2^-t`. Its explicit witness is the already checked hybrid map; there is no supplied start, fallback, branch, count, step contract or accuracy premise. It includes zeros, empty lists and t=0. The compact endpoint therefore closes the ordinary list-program feasibility/distribution contract without asserting a formal encoded machine or charged runtime theorem.
