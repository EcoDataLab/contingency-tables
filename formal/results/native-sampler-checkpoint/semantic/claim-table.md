# Actual compiled sampler claim map

The completed native audit checked 25,448 selected declarations, including 18,054 theorems, 11,951 imported modules and 22 exact headline dependency closures. This is an AI readback of that actual compiled evidence and its pinned source definitions; it is not another Lean execution.

The final theorem establishes one fixed fair-bit machine with global natural constants C > 0 and D. For every finite pair of dimensions and natural row and column margins with equal totals, and every h ≥ 1, every tape of length t = C·S^D halts with a feasible original table, and the output distribution at that same time has normalized total variation at most 2^−h from uniform. Here S = m + n + clog₂(sum(r)+1) + h + 1. Empty dimensions and zero margins are included when totals agree.

The final theorem’s own closure reaches the refined d^17 Poincaré route, U = 5d³ and L = 3d, the computed walk schedule and both implemented completion branches. It retains the computed initial state, original greedy fallback, rejection mass, fresh uniform words and literal matrix output. No supplied oracle or stationary-start hypothesis remains in the final claim.

The full runtime degree is proved to exist. Its numeric value has not been extracted: the source chooses D = 170·P.natDegree for an existential compiler polynomial P. The intermediate powers 17, 85 and 170 are not numeric complete runtime degrees or runtime measurements. The supplied-bank cost result is separate and assumes an exact reserved bank; the formal fair-bit machine bridge accounts for acquiring bits.
